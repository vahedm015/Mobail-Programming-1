# تمرین ۵: مقایسه روش‌های توسعه موبایل

| معیار مقایسه | Flutter | توسعه Native با Kotlin | Apache Cordova |
| :--- | :--- | :--- | :--- |
| **زبان برنامه‌نویسی** | Dart | Kotlin | HTML, CSS, JavaScript |
| **نحوه ساخت رابط کاربری** | با استفاده از ویجت‌های خود فلاتر (مستقل از سیستم‌عامل) | با استفاده از XML یا Jetpack Compose (اختصاصی اندروید) | با استفاده از HTML و CSS داخل WebView |
| **مزایا** | - عملکرد بسیار بالا (شبیه به نیتیو)<br>- کراس‌پلتفرم (یک کد برای اندروید و iOS)<br>- رابط کاربری زیبا و یکپارچه | - بهترین عملکرد و سرعت<br>- دسترسی کامل و مستقیم به تمام APIهای سیستم‌عامل<br>- پشتیبانی رسمی گوگل | - یادگیری بسیار آسان (چون فقط وب است)<br>- استفاده مجدد از کدهای وب موجود<br>- ساخت سریع پروتوتایپ |
| **محدودیت‌ها** | - حجم اپلیکیشن بالاتر<br>- نیاز به یادگیری زبان جدید (Dart) | - فقط برای یک سیستم‌عامل (اندروید)<br>- هزینه و زمان بیشتر برای ساخت نسخه iOS | - عملکرد ضعیف‌تر (به دلیل WebView)<br>- تجربه کاربری کمتر شبیه به نیتیو<br>- وابستگی زیاد به افزونه‌ها |
