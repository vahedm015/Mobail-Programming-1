تمرین ۶: تفاوت میان String و String? در کاتلین

در کاتلین، String و String? دو نوع متفاوت هستند که از نظر پذیرش مقدار null با هم فرق دارند.

۱. String (غیرقابل تهی بودن / Non-nullable):
- متغیری از نوع String نمی‌تواند مقدار null را نگه دارد.
- اگر بخواهید به آن null بدهید، کامپایلر خطا می‌دهد.
- مثال:
  val name: String = "Ali"   // صحیح است
  val name2: String = null   // خطا! (کامپایل نمی‌شود)

۲. String? (قابل تهی بودن / Nullable):
- متغیری از نوع String? می‌تواند یا یک مقدار متنی داشته باشد یا null.
- این یعنی به کامپایلر می‌گویید: «این متغیر ممکن است خالی باشد.»
- مثال:
  val name: String? = "Ali"  // صحیح است
  val name2: String? = null  // صحیح است

چرا این موضوع مهم است؟
کاتلین از این ویژگی برای جلوگیری از خطای NullPointerException (یک خطای بسیار رایج در زبان‌هایی مثل جاوا) استفاده می‌کند. با استفاده از String?، شما مجبور می‌شوید احتمال null بودن را به‌صورت ایمن مدیریت کنید.
